# Homebrew tap for newgit

```sh
brew install spheroman/newgit/newgit
```

[newgit](https://github.com/Spheroman/newgit) gives every branch its own
workspace, env files, dependencies, and running services.

`Formula/newgit.rb` is generated by `scripts/homebrew-formula.sh` in
Spheroman/newgit and committed here by its release workflow, so edits made
here are overwritten by the next release.
